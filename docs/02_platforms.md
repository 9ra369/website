# ホスティングプラットフォーム比較

前提: [01_tech-stack.md](./01_tech-stack.md) の通りAstroによる静的サイトを採用。
「無料で始めて、広告収益が出たら有償プラットフォームに切り替えたい」という要望に対する比較・提案。

## 無料ホスティング候補比較

| 項目 | **Cloudflare Pages（推奨）** | Vercel | Netlify | GitHub Pages |
|---|---|---|---|---|
| 無料枠の帯域 | 無制限 | 100GB/月 | 100GB/月 | ソフトリミットあり（目安100GB/月） |
| ビルド回数 | 500回/月 | 制限あり（Hobbyは商用不可） | 300分/月 | 制限あり |
| **商用利用（広告掲載）の可否** | **明示的に可**（無料枠でも広告収益OK） | ⚠️ **Hobbyプランの規約上、商用利用は原則不可**（広告収益サイトはPro以上が必要になりうる） | 個人利用の範囲なら概ね可だが、規約変化に注意 | 明確な禁止規定はないが商用色が強い運用は非推奨との情報あり |
| カスタムドメイン | 無料・簡単 | 無料 | 無料 | 無料（DNS設定はやや癖あり） |
| ビルド時間 | 十分速い | 速い | 速い | 遅め |
| サーバーレス関数（将来の拡張用） | Pages Functions（無料枠あり） | Serverless/Edge Functions | Netlify Functions | 不可（純粋な静的ホスティングのみ） |
| 独自ドメイン取得 | Cloudflare Registrar（原価販売で割安） | 別途取得が必要 | 別途取得が必要 | 別途取得が必要 |
| 有償プラン移行のしやすさ | Workers Paid（$5/月〜）でR2ストレージ・D1 DB等も同エコシステムで拡張可能 | Pro（$20/月〜） | Pro（$19/月〜） | 有償プランなし（Pages自体は無料専用） |

**結論: Cloudflare Pages を採用。**
広告収益化を前提とするなら、Vercel Hobbyプランの「非商用利用限定」規約に抵触するリスクを避けられる点が決定的。帯域無制限・ビルド成果物をそのまま配信するだけの構成とも相性が良い。

## 有償プラットフォームへの移行パス（収益化後）

現時点でCloudflare Pagesを選んでおけば、以下のように**同じエコシステム内で段階的にアップグレード**でき、大規模な作り直しが発生しない。

| 段階 | 内容 | 目安コスト |
|---|---|---|
| Phase 1: MVP公開 | Cloudflare Pages（無料）＋独自ドメイン（年間1,000〜1,500円程度） | 年間 ~1,500円 |
| Phase 2: 収益化開始 | AdSense審査通過、Cloudflare無料枠のまま運用継続（静的サイトなら無料枠で十分なケースが多い） | 変わらず |
| Phase 3: 機能拡張したくなったら | Cloudflare Workers Paid（$5/月）でD1（DB）・R2（画像/大容量ストレージ）・KVを追加し、コメント数集計や閲覧数ランキング等の動的機能を追加 | 約750円/月〜 |
| Phase 4（任意）: 完全自前運用 | さくらのVPS / ConoHa VPS / Lightsail 等に静的ビルド成果物＋Nginxで移設。広告以外の収益源（アフィリエイト、有料noteリンク等）を増やす場合に検討 | 月額500〜1,000円〜 |

**ポイント**: 静的サイトである限り「引っ越し」は成果物フォルダをコピーするだけなので、Phase 1で立てたサイト構造・デザインをそのまま維持して移行できる。無理に最初から有償プランやVPSを選ぶ必要はない。

## AdSense導入における注意点（プラットフォーム非依存の共通事項）

- 審査には「独自性のある十分な量のコンテンツ」が必要。単なるリンク集ではなく、各エントリーに自分の解説・メモ・評価を添える構成（[03_spec.md](./03_spec.md) のコンテンツスキーマ参照）が有利
- プライバシーポリシー・お問い合わせページの設置が事実上必須
- Cookie同意バナー（CMP）の設置が地域によって必要になる場合がある（EU/UK等からのアクセスがある場合）
