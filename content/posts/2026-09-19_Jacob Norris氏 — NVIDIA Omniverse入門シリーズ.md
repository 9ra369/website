Sierra DivisionのCreative Director、Jacob Norris氏が、NVIDIA Omniverseの入門動画シリーズをArtStationでまとめて紹介しています。全6本の構成は以下の通りです。

1. What is NVIDIA Omniverse?
2. What is the USD File Type? | Getting Started in NVIDIA Omniverse
3. Setting Up A Project in NVIDIA Omniverse Create Part 1: Getting Started
4. Setting Up A Project in NVIDIA Omniverse Create Part 2: Lighting & Rendering
5. Project Management in NVIDIA Omniverse Create
6. Working with Layers & Deltas in Omniverse Create | Getting Started in NVIDIA Omniverse

本人のコメントによると、UIとレンダリング性能の両面で急速に進化しているOmniverseについて「実際のところ何なのか」「USDとは何か」「アーティストとして何ができるのか」を一通り説明することを目的としたシリーズとのこと。

Blender・Mayaなど複数のDCCソフトをUSD経由でOmniverse上に統合する運用は、まだ触ったことがない人には最初のハードルになりがちなので、こういう順序立てた入門シリーズがあるのはありがたいです。プロジェクトの立ち上げからレイヤー/デルタの概念まで一通り追えるので、これからOmniverseを触ってみたい人の最初の1本としてちょうど良さそうです。
（Jacob Norris氏、分かりやすいシリーズの公開ありがとうございます）
